# 大病历生成器

一个**离线、单文件**的网页工具，帮你在手机上把问诊和查体的内容整理成一份规范的大病历。
不用联网、不用装 App、数据只存在你自己手机里。

**在线入口：<https://xjb1337.github.io/bingli/>**

安卓 Chrome 打开后，菜单「添加到主屏幕」，用起来和 App 一样。详见 [使用说明](#一怎么放到手机上)。

---

## 一、怎么放到手机上

### 方法 1：直接打开在线地址（推荐）

1. 手机 Chrome 打开 <https://xjb1337.github.io/bingli/>
2. 点右上角「⋮」→「添加到主屏幕」→ 添加
3. 以后从桌面图标进入

> **首次打开需要联网**，之后浏览器会缓存页面，断网也能打开。
> 如果哪天打不开，联网刷新一次即可。

### 方法 2：离线文件（完全不联网也能用）

把 `dist/大病历生成器.html` 通过微信文件传输助手发到手机，用 Chrome 打开，
再「添加到主屏幕」。适合没网或想彻底断网的场合。

### 方法 3：电脑上先用

双击 `dist/大病历生成器.html` 即可在电脑浏览器使用。

> **两种方式的数据不互通**！在线版和本地文件版是不同的网址，浏览器分开存数据。
> 请固定用其中一种，需要迁移时用「病历 → 导出备份 / 导入备份」。

## 二、填写流程

顶部有 12 个步骤，按顺序填，几乎全部是**点选**，只有主诉、现病史需要打字。

**步骤顺序就是病历章节顺序**（既往史在系统回顾之前，和【】标题出来的次序一致），不用记两套。

**想直接跳到某一步**：点顶部那一行的「**目录 ▾**」，弹出全部 12 步，每步右侧标着「已填 / 填了一部分 / 还没填」，点哪行走哪行。补第 7 步不用再按六次「下一步」。

| 步骤 | 内容 | 要点 |
|---|---|---|
| ① 基本情况 | 姓名、性别、年龄、**科室**、病历号、现住址、主诉 | **先选科室**，后面查体会自动带出该科专科查体；选完科室还能套一份模板病例 |
| ② 现病史 | 起病、**诱因**、症状特点、**缓解因素**、进展、伴随、**鉴别意义阴性病史**、诊治经过、一般情况 | 可点"一键生成初稿"再改 |
| ③ 既往史 | 慢性病、**长期用药**、手术外伤、过敏、疫苗 | 手写"疾病详情"会优先于勾选 |
| ④ 系统回顾 | **8 个系统、91 个症状**（按《诊断学》第10版） | 三态：**没点=没问，不写**；点一下=阴性「无X」；再点一下=阳性。它是既往史的补充追问，所以排在既往史后面 |
| ⑤ 个人史 | 出生地、吸烟饮酒、接触史 | 吸烟选"有"后填具体量 |
| ⑥ 婚姻与生育史 | 婚姻、月经、生育 | 女性才出现月经史 |
| ⑦ 家庭史 | **类似疾病**、**两系三代遗传病**、父母健康情况 | |
| ⑧ 体格检查 | 生命体征 + 通用查体 + **本科室专科查体** + 重点查体 | 每项都有「本次检查」勾选框和"常用描述"快捷选项 |
| ⑨ 实验室检查 | 检查项目和结果 | 可加多行 |
| ⑩ 摘要与诊断 | 质控提醒、诊断参考提示、初步诊断、病历摘要、**首次病程录 SOAP**、**出院记录** | 提示仅作参考，需自己判断 |
| ⑪ **评分自查** | 对照规培评分表逐项打分 + **问诊深度自查** | 见下方"第五节"与"第五点五节" |
| ⑫ 生成病历 | 三种文书切换、复制、下载 | 大病历 / 首次病程录 / 出院记录 |

合计 **12 个科室 53 个病种**（通用科不在内）。点开卡片会显示「共 N 个病种」和每个病种的典型诊断，方便你判断哪个接近你的病人。

> 产科和妇科在科室选择器里是**两个独立选项**，模板也是分开放的：选「产科」只看到产科那 3 个
> （妊娠、子痫前期、妊娠期糖尿病），选「妇科」只看到妇科那 3 个（盆腔炎性疾病、子宫肌瘤、异位妊娠）。

套用模板有三条硬规矩：

1. **只补空白，不覆盖**。你已经写过的内容一个字都不会被改——姓名、主诉、现病史、诊断全部原样保留，模板只往空着的地方填。
2. **患者身份留空**。姓名、性别、年龄、住院号、床号、入院日期都不写，必须你自己填。生命体征也全空——那是你自己测出来的数字，模板不能替你编。
3. **套完必须改**。模板是教学用的标准病例，不是你的病人。体征写的是这个病的典型表现，你查不到就是查不到，不能照抄。

套用后挂号科室也会一起补上（如果你还停在通用科），否则该科专科查体出不来。想反悔就重新套一份，或者直接改——模板不锁定任何字段。

> 模板数据在 `tools/tpl-parts/*.cjs`，改完跑 `node tools/gen-templates.js` 重新生成，
> 再用 `node tools/check-templates.js tools/tpl-parts/*.cjs` 自检（会把每个查体值拿去和
> 选项表逐字比对，`abdPalpation: '中上腹压痛'` 这种自己改词的错误当场报出来）。

### 几个省时间的设计

- **主诉实时预览**：症状和时长写在同一个框里（"发热、咳嗽、咳黄痰3天"），下面立刻预览拼好的主诉，不用自己再整理一遍。
- **生命体征一键填**：点"填入正常值"一键填 36.5 / 78 / 18 / 120/80，再改异常项。
- **BMI 自动算**：填了身高体重，自动显示 BMI 和胖瘦分级。
- **查体快捷描述**：每个查体下面"常用描述"里点一下即可替换默认正常描述。
- **质控提醒**：会提示"主诉含诊断性词语""主诉超过20字""初步诊断未填"等。
- **评分自查**：告诉你对照规培评分表还缺哪些得分项，并按"能补回多少分"排序。

### 系统回顾按《诊断学》第10版分 8 个系统

第 ③ 步的问诊清单不是随手列的，系统划分和症状条目都对齐《诊断学》第10版，
从旧版的 12 个系统归并成 **8 个系统、91 个症状**：

| # | 系统 | 症状数 | 例子 |
|---|---|---|---|
| 1 | 呼吸系统 | 13 | 咳嗽、咳痰、咯血、呼吸困难、胸痛、喘息、发热、盗汗、咽痛 |
| 2 | 循环系统 | 8 | 心悸、心前区疼痛、夜间阵发性呼吸困难/端坐呼吸、下肢水肿、发绀、晕厥 |
| 3 | 消化系统 | 14 | 恶心、呕吐、呕血、腹痛、腹泻、便秘、黑便、反酸烧心、黄疸 |
| 4 | 泌尿系统 | 8 | 尿频尿急尿痛、血尿、尿量减少、夜尿增多、腰痛/肾区疼痛、尿道分泌物 |
| 5 | 血液系统 | 13 | 乏力、面色苍白、易出血/出血难止、鼻出血、淋巴结肿大、骨痛 |
| 6 | 内分泌及代谢系统 | 11 | 多饮、多食、多尿、怕热多汗、怕冷少汗、颈部肿块、体重下降 |
| 7 | 神经精神系统 | 20 | 头痛、头晕、眩晕、视物模糊、肢体麻木、肢体无力、抽搐、失眠 |
| 8 | 肌肉骨骼系统 | 4 | 关节疼痛/肿胀、晨僵、腰背痛、肌肉酸痛无力 |

系统回顾是**三态**的，这是本工具最需要注意的一处：每个症状点一下是**阴性**（写"无咳嗽"），
再点一下是**阳性**（写"咳嗽3天，干咳"），第三次点回到**没问**。

- **没点过的症状，病历里一个字都不出现**——没问就是没问，不能替你写"无"；
- 一个系统里一个症状都没点，这个系统在病历里整行不出现；
- 整段一个症状都没点时，【系统回顾】这一节写「／」。

嫌逐系统列阴性太长，可以在生成设置里把「系统回顾详略」切成**只写阳性**：
那样只输出有阳性症状的系统，一个阳性都没有时整段不输出。

### 查体勾选制：没查的项，病历里一个字都不写

第 ⑧ 步每个查体项左边都有一个 **「本次检查」勾选框**，它是"这一项要不要写进病历"的总开关。

**所有查体项默认都不勾**，包括通用查体。理由很直接：《诊断学》第10版要求病历「必须客观地、真实地
反映病情和诊疗经过，避免任何臆断或虚构」。你没勾，就等于这次没查；工具替你写一句"未见异常"，
那不是帮你，是让你在带教面前交一份假病历。

| 类型 | 默认状态 | 说明 |
|---|---|---|
| **通用查体**（一般状况、皮肤、头颈、心肺腹、脊柱四肢、神经系统） | **默认不勾** | 真查了才勾。一整组懒得逐个点，卡片上有「全选」 |
| **专科查体**（本科室的专项检查，每科 9～11 项） | **默认不勾** | 只有本科室才查 |
| **通用查体里的细分项**（肝/脾/胆囊/肾/膀胱触诊、液波震颤、振水音、布氏征、克氏征、巴氏征、下肢水肿、四肢肌力等 16 项） | **默认不勾**，且勾父项不会连带勾它们 | 上一级那句"肝脾肋下未触及""病理反射未引出"已概括；要单独写这一项才勾 |

规则四条：

- **没勾的项，病历里完全不出现**——不会写"未查"、不会写"未做"，那一句直接没有；
- **勾了但没填具体所见**，状态显示为灰色「系统默认」，生成时写该项的**规范正常描述**
  （如"气管居中""肝肋下未触及，肝区无压痛"）。**这是你勾了"查过"的意思**，不是工具替你编的；
- **细分项写了字，概括项让位**：勾了"肝"并真的填了所见，腹部触诊里那句"肝脾肋下未触及"就不再写，
  免得两句互相打架——**子项只勾不填时不动概括项**，避免重复；
- **旧存档会自动兼容**：某一项里已经有你手写的字，即使没有勾选记录，也当作已勾——写过的体征不会凭空消失。

所以正常流程是：进查体页 → 哪组查了就把那组的「全选」点一下 → 只改掉本例异常的那几项 →
再勾上这次真做了的专科查体。专科查体一处不勾，这一整段就不会出现在病历里。

### 没填的项写「／」，不留空也不替你填

《诊断学》要求「所有表格项都应详细填写，无内容者画'/'或'—'」。本工具统一用**全角「／」**
（U+FF0F），并且**一定保留项目名**：

```
手术史：／。
月经史：初潮 ／岁，经期 ／天，周期 ／天，末次月经 ／。
```

空节也一样——【主诉】【婚姻史】这些即使一个字没填，标题仍然在，内容写「／」。
这样打印出来交给带教，一眼就能看出哪几项还没问，而不是被悄悄省略掉。

### 体格检查书写对齐《诊断学》第10版

生成的体格检查不是把勾选项拼起来就完事，排版和句式按教材（第六篇病历书写）的写法来：

- **一般状况一整句逗号连写**：发育、营养、神志、体位、面容与表情、能否合作，中间用逗号，
  只在最后收一个句号——「发育正常，营养中等，神志清楚，精神可，自主体位，查体合作。」
  其他查体组仍是逐句句号断开。
- **腹部顺序固定为 视诊 → 听诊 → 叩诊 → 触诊**：触诊叩诊会改变肠鸣音，所以听诊必须排在前面，
  这是查体手法分里会单独看的一项。
- **专科情况不重复通用查体已写的内容**：教材原话是"前面体格检查中的相应项目不必重复书写"，
  专科段里如果某项的每一句都能在前面找到，整项就不再写一遍。
  判定按**整项**比对而不是按分句删——分句级删除会留下"质中，活动度好"这种缺主语的残句，
  重复只是啰嗦，残句是信息损坏。
- **肺、心脏**按视诊/触诊/叩诊/听诊分段缩进书写，与纸质病历一致。

## 三、导出与保存

- 点右上角 **复制**（在生成页）→ 粘贴到微信、备忘录或医院的电子病历系统；
- 点 **下载 .txt** → 存成文本文件；
- 点 **复制某段** → 只需要"现病史"或"体格检查"时单独复制；
- 点 **保存** → 存进本机，右上角 **病历** 可查看、切换、删除历史病历；
- 点 **病历 → 导出备份** → 存成 `.json` 文件，这是**唯一可以用来换手机/找回数据**的方式；
- 点 **病历 → 导入备份** → 支持合并（保留现有、同 ID 取较新）或替换。

> ⚠️ 数据保存在**当前浏览器**里。不要在浏览器设置里清"网站数据"，否则记录会丢。
> 换手机、重装浏览器前，**必须先导出备份**并保存到手机外（微信收藏、电脑）。
>
> 如果保存失败（存储空间满或隐私模式），页面顶部会显示红色告警，**不会假装保存成功**。
> 如果本地存档损坏，工具会保留原始数据不覆盖，并提示你先备份。

## 四、诊断参考提示怎么用（重要）

第 ⑩ 步的"诊断参考提示"是**根据你填的阳性发现自动匹配的清单**，作用是提醒你不要漏掉需要鉴别的疾病。

- 它**不会自动写入**病历，只有你点"加入诊断"才会加进去；
- 它**可能误报或漏报**，只是辅助记忆，不能代替你的判断；
- 提示里附带的"可补充：…"是建议进一步做的检查，供你参考。

请始终以自己的临床判断和带教老师的意见为准。

## 五、评分自查怎么用（对照规培结业考核）

第 ⑪ 步「评分自查」依据《浙江省住院医师规范化培训临床实践能力结业考核（内科）》评分表，
把你的病历逐项对照打分，告诉你**还缺哪些得分项**。

### 它检查四个考站

| 考站 | 评分表 | 检查内容 |
|---|---|---|
| 病史采集 | 第 2 页 | 主诉是否含诊断名、有无诱因/缓解因素/鉴别意义阴性病史、既往史六项、个人史、两系三代家族史 |
| 体格检查 | 第 3–4 页 | 各区域是否都记录、**腹部次序是否视听叩触**、神经四征是否分列、重点查体、鉴别意义阴性体征 |
| 首次病程录 | 第 5 页 | SOAP 四段完整性、诊断依据是否逐条对上、鉴别诊断是否展开 |
| 病历书写 | 第 6–7 页 | 入院记录各章节、首次病程记录、出院记录 |

### 两个数字要分清

- **得分**：只统计"病历纸面上能核对"的部分；
- **现场动作分**：问诊技巧、医患沟通、查体手法这类**考场上做出来的动作**，工具不评，只列出来提醒你。这部分约占 49 分。

所以自查显示的不是你考试能拿多少分，而是**你的病历写全了没有**。

> 这一页下面还有一块「**问诊深度自查**」，回答的是另一个问题：格式齐了，但问得够不够深。
> 详见下面第五点五节。

### 关于「默认描述」

查体项**勾了「本次检查」但没填具体所见**时，生成的是该项的系统预置正常描述（比如"气管居中"）。
状态条是灰色「系统默认」而不是绿色「已填」——这两者工具分得很清楚：绿色是你自己写的字，
灰色是你勾了"查过"、但描述还是现成的。自查计分认的是**文字是否进入病历**，
所以两者都算写过，但灰色项会单独统计出来提醒你核对。

没勾的项不会写进病历——没查过的体征不算写过，也不计分。

### 它不会替你做什么

- **不会给出诊断结论**：只有"还缺什么"的提示；
- **不会替你编鉴别诊断和诊疗计划**：那两段留空让你自己写；
- **不会补造没做的体征**：你只写"压痛"，它不会自动补出"反跳痛"；
- **不会替你写"否认高血压"**：既往史没勾就没勾，病历里写「疾病史：／」；
- **不会替你写"全身浅表淋巴结未触及肿大"**：没勾的查体项一句都不写；
- **不会替你写"无痛经""性生活正常"**：这些只有你自己填了才会出现；
- **不会替你写具体数字**：查体的默认正常描述里没有"心率78次/分""肠鸣音4次/分"
  这类数值——那个数字没人量过。生命体征填了 88、查体又写着 78 时，会提示两者不一致。

### 撞车了会提醒，但不替你改

如果你自己勾了通用腹部触诊（用的是系统默认的"全腹无压痛、反跳痛"），又在消化内科专科查体里
写了"中上腹压痛"，同一份病历里两个相反的体征。工具会在生成页顶部提示这条冲突，
但**不会擅自删掉任何一边**——那是你自己勾的、自己写的，删哪句该由你决定。

> ⚠️ 这是备考自查工具，**不能代替带教老师、考官或上级医师的评判**。

## 五点五、问诊深度自查（它挑的是「问得够不够深」）

评分自查回答的是「病历格式齐不齐」，这一栏回答的是另一个问题：
**你写了这个症状，但写够了没有？** 带教老师查房时最爱追问的那些点，都收在这里。

它只读你自己敲进去的字——模板内容、系统默认描述都不算。所有结论都只是提醒，
不会进病历正文。

### 它现在会挑什么

| 提醒 | 判据 | 出处 |
|---|---|---|
| 黑便没写次数或量 | 只写"解柏油样黑便"，没有"每日几次""一个鸡蛋大小" | 「一个鸡蛋大小」「半瓶矿泉水」这种具象说法 |
| 呕吐没写次数、呕吐物性状 | 只写"伴呕吐" | 带教点名"呕吐未写次数/天+性状+与进食腹痛关系" |
| 腹痛没区分持续性/阵发性 | 只写"上腹隐痛" | 同上 |
| 一条阴性症状都没有 | 现病史里没有任何"无发热""无呕血黑便" | 「你这里面没有写任何的阴性症状」 |
| 慢性病只写病名没写药 | 勾了高血压/糖尿病，但没写用什么药、控制得怎样 | 「高血压的药尽量要问出来」 |
| 手术史没年份/医院/术式 | 只写"阑尾切除术" | 「几几年做的，在哪里做的手术，手术过程是怎样的」 |
| 心血管病人没问抗栓药 | 勾了冠心病/脑卒中，但全文没有阿司匹林/氯吡格雷 | 术前要停 5-7 天 |
| 主诉与现病史天数对不上 | 主诉 1 月、现病史 3 天 | 「上面七天，下面不要写六天」 |
| 主诉没追溯到完整病程 | 主诉 3 天，现病史却提到数月前 | 「这个病史就要从之前他的头晕开始讲」 |
| 影像/内镜没抄分级 | 做了乳腺 B 超却没写 BI-RADS、胃镜没写 Forrest | 「BI-RADS 几级、建议手术这一段全丢了」 |
| 乳腺/甲状腺没问月经史 | 女病人、主诉涉及乳腺或甲状腺 | 「不要不好意思问，病历上面都要写下来」 |
| 儿科没写出生史喂养史 | 3 岁患儿，个人史三块全空 | 儿科个人史必填 |
| 辅助检查没写在哪做的 | 全部没填机构 | 要分清本院与外院 |
| 「14日」有歧义 | 裸的日号大于 12 | 应写「三天前」或「10月14号」 |

### 它刻意不报的

**写清楚了就不许报。** 学生被冤枉两次就会关掉整页，所以规则里大量是反例测试：
「无呕吐，无黑便」不算写了呕吐；「否认手术史」不算手术史没写清；
「数月来体重下降」不会被当成主诉该往前追溯（差十倍以上才算漏追溯）；
男性甲状腺病人不要求月经史；普通腹痛的女性也不要求。

## 六、几个常见问题

**Q：换手机 / 换浏览器，数据还在吗？**
不在。数据存在打开它的那个浏览器里。换设备请用"下载 .txt"迁移。

**Q：能填好几个病人吗？**
可以。点右上角"病历"→"新建病历"。

**Q：科室选错了怎么办？**
回第 ① 步改，第 ⑧ 步的专科查体会跟着变（已填的通用查体内容不会丢）。

**Q：生成的文字不满意？**
每个查体项都是可编辑文本框，直接改；主诉、现病史也一样。你写的优先，工具只做拼接。

**Q：会不会把数据传出去？**
不会。整个工具是单个 HTML 文件，不联网、不发请求，没有服务器。

`tools/tpl-parts/` 里现成的写一份纯数据文件，不需要改程序。

### 几个关键约束（改代码时请守住）

1. **改任一 `src/` 文件后必须 `node build.js`**，否则手机拿到的是旧代码。
   `tests/artifact.test.cjs` 会逐行比对产物与源码，忘记构建会直接测试失败。
2. **存储与数据校验只能写在 `core.js`**，不要写进 `app.js`。
   这样边界行为（存档损坏、存储写满、导入恶意 JSON）才能被单测覆盖。
3. **保存失败绝不能提示"已保存"**。写完后要检查返回值，失败时显示顶部告警。
4. **损坏的存档不得静默覆盖**。读取失败时原数据必须原样保留。
5. 新增科室：改 `schema.js` 的 `PE_SPECIAL` 和 `DEPARTMENTS`，再跑 `npm run verify`。
6. 新增诊断提示：改 `hints.js` 的 `RULES`，`must` 是必须命中的条件，能有效减少误报。
   新加规则后跑 `node tools/verify-review-cases.js` 看 48 条真实写法用例是否仍全部判对。
7. **新增模板病例**：在 `tools/tpl-parts/` 放一个 `.cjs`，照 `CONTRACT.md` 写，
   然后 `node tools/check-templates.js tools/tpl-parts/*.cjs`（0 问题）→
   `node tools/gen-templates.js` → `node build.js` → 跑 `tests/templates.test.cjs`。
   查体值必须**逐字**取自 `tools/pe-options.txt`，自己改词会被自检报错——
   因为学生在界面里看到的是那张选项表，改过的词在快捷选项里根本点不到。

`src/` 是源码，`dist/` 是产物，**不要手改 `dist/`**——它每次都会被打包覆盖。

### 生成的病历结构

按医院现行病历格式，各章节如下（`node test/samples.js` 可看完整示例）：

```
【一般项目】（逐行一项，缺项写「／」）
    姓名／性别／年龄／科别／床号／住院号／民族／籍贯／出生地／婚姻／
    职业／工作单位／通讯地址／电话号码／入院日期／记录日期／
    病史陈述者／病史可靠程度
【主诉】
【现病史】
【既往史】（逐项：既往健康状况、疾病史、传染病史、预防接种史、过敏史、
          手术史、外伤史、输血史、中毒史、长期用药、与本病相关病史）
【系统回顾】（8 个系统；没问过的症状不写）
【个人史】（母孕史、出生史、喂养史、生长发育史、居住、嗜好、接触史、
          冶游史、职业与工作条件）
【婚姻史】（婚姻状况、结婚年龄、配偶健康、性生活、夫妻关系）
【月经与生育史】（月经史 + 生育史四项式「足月-早产-流产-存活」+ 避孕措施）
【家庭史】（类似疾病、传染病史、遗传性疾病史，三个独立问题）
【体格检查】（一般状况 / 皮肤粘膜 / 淋巴结 / 头颅及其器官 / 颈部 /
          胸部→肺·心脏 / 腹部→视诊·听诊·叩诊·触诊 /
          生殖器肛门直肠 / 脊柱及四肢 / 神经系统 / 本科室专科查体）
【实验室检查】
【摘要】
【诊断依据】（逐条列出每条诊断的病史 / 体检 / 辅助检查）
【初步诊断】（分条编号 + 医师签名）
```

**每一节都会出现**，即使一个字都没填——标题保留，内容写「／」。
这是《诊断学》的要求（「所有表格项都应详细填写，无内容者画'/'或'—'」），
也是为了让带教一眼看出你哪几项还没问，而不是被悄悄省略掉。

其中体格检查的「肺」「心」按视诊/触诊/叩诊/听诊分段缩进书写，
腹部固定为**视诊 → 听诊 → 叩诊 → 触诊**（触诊叩诊会改变肠鸣音，听诊必须在前）。

### 哪些必须填、哪些可以留空

每个字段右边都有角标，分三档：

| 角标 | 含义 | 留空的后果 |
|---|---|---|
| 🔴 **必填** | 姓名、性别、年龄、科室、主诉 | 病历开头就是残缺的，没法交 |
| 🟡 **建议填** | 病历号、起病情况、症状特点、诊治经过、手术/外伤/输血史、生命体征等 | 能生成，那一处写「／」占位 |
| ⚪ **可留空** | 绝大多数查体项、系统回顾 | 没勾的完全不写；勾了但没填的写该项规范正常描述 |

第 ⑫ 步「生成病历」页顶部有「填写情况」总览，会实时列出还差哪些必填项、哪些建议项没填，
以及查体里有多少项已经勾选。

**查体页的四种状态**要分清（由「本次检查」勾选框决定）：

- ⬜ **未查** —— 没勾选，本次没做这一项，病历里完全不出现（不写"未查"）
- 🟢 **已填** —— 勾了且你自己填过
- ⚪ **系统默认** —— 勾了但没填，框里显示的是该项预置的正常描述；生成时会写进病历，
  自查时也算分，但会单独标注为"尚未核对"（改一个字就算已填）
- 🔴 **需填** —— 勾了，但这一项既没有默认值也没有规范正常描述，留空病历里就没有这句
  （当前版本所有查体项都配了正常描述，所以这个角标基本不会出现，留着是为了以后加新项时不会静默漏写）

> 实用建议：进查体页先按组点「全选」（每组标题右侧有），再改掉本例异常的那几项，
> 最后勾上这次真做了的专科查体。没勾的项不会出现在病历里，也不会替你编。
