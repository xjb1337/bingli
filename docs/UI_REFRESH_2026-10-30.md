# 图标与界面更新（2026-10-30）

采用松绿色、暖纸白的病历工作台视觉。桌面图标为原生 adaptive vector，网页标识与 favicon 使用相同的病历夹、医疗加号和核对标记，不加载外部字体或图像。

- 新增 assets/app-icon.svg 和 Android 自适应图标、应用主题资源。
- 页头统一品牌标识与保存、病历、导出图标，保留原控件 ID 和流程。
- 卡片、输入框、查体组、目录弹层与生成页统一边框、间距和配色；保留阳性/告警状态区别。
- 底部改为两列导航＋独立版本行，修复原版本号 width:100% 挤压按钮导致竖排。
- 移除 Android 顶部整条灰色更新按钮；检查更新保留在底部，显示真实 APK 版本。
- 支持深色模式与减少动态效果偏好。
- 处理普通屏幕配置变化时保留当前 WebView，并在 Activity 销毁时清理 WebView、文件选择回调和更新任务，避免旧 WebView 定时保存造成自冲突。

本地验证：npm run verify 625/625；Android 更新校验 9/9；assembleRelease 与 lintRelease 通过。雷电 Android 9 / WebView 91 录入数据保留，基本情况、查体、摘要、生成页均无横向溢出；320、412、980 CSS 宽度导航按钮高 48px，横竖屏切换 PID 不变且冲突状态为 false。测试截图和测量日志在本地 tmp-review/，不提交。
